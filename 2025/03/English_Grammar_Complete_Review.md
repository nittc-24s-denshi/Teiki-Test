## **第1章：仮定法 (Subjunctive Mood)**

仮定法とは、現実との「心理的・時間的距離」を表現するために、時制を過去方向へシフトさせる手法です。

### **1\. 基本時制の原理 (Lesson 26\)**

| 種類 | 内容 | If節の時制 | 主節の時制 | 備考 |
| :---- | :---- | :---- | :---- | :---- |
| **仮定法過去** | **現在の事実**に反する | 過去形 | 助動詞の過去形 (would, could, might) ${+}$ ${V_{root}}$ | 今～なら、...なのに |
| **仮定法過去完了** | **過去の事実**に反する | 過去完了形 (had ${p.p.}$) | 助動詞の過去形 ${+}$ have ${p.p.}$ | あの時～だったら、...だったのに |
| **混合型** | 過去の原因 ${to}$ 現在の結果 | 過去完了形 | 助動詞の過去形 ${+}$ ${V_{root}}$ | あの時～だったら、今は...なのに |

### **2\. 重要慣用表現 (Lesson 27\)**

#### **2.1 願望 (I wish / as if)**

* **I wish**: 実現していない願望。  
  * ${I \ wish \ S \ V_{past}}$: （今）～ならいいのに。  
  * ${I \ wish \ S \ had \ V_{p.p.}}$: （あの時）～だったらよかったのに。  
* **as if**: 事実とは異なる比喩。  
  * ${as \ if \ S \ V_{past}}$: まるで（その時）～であるかのように（主節と同時）。  
  * ${as \ if \ S \ had \ V_{p.p.}}$: まるで（それより以前に）～であったかのように。

#### **2.2 「～がなければ」 (If it were not for...)**

| 時制     | 表現パターン                                   | 倒置 (If省略)                           |     |
| :----- | :--------------------------------------- | :---------------------------------- | --- |
| **現在** | ${If \ it \ were \ not \ for \ A}$       | ${Were \ it \ not \ for \ A}$       |     |
| **過去** | ${If \ it \ had \ not \ been \ for \ A}$ | ${Had \ it \ not \ been \ for \ A}$ |     |
| **共通** | But for A / Without A                    |                                     |     |

#### **2.3 未来の仮定と提案**

* **If S should...**: 「万一～なら」。主節は直説法（will）も可能。  
* **提案・要求のthat節**: suggest, insist, order などの後は、動詞の原形（または should ${+}$ 原形）を用いる。  
  * 例: *The doctor insisted that Ben ( **give** ) up drinking.* (Ben gives ではない)

## **第2章：話法 (Narration) \- Extra Lesson 4**

他者の発言を伝える形式の変換です。

### **1\. 転換の3要素**

1. **人称 (Person)**: 誰から誰への発言かに合わせて変更。  
2. **時制 (Tense)**: 伝達動詞が過去なら、中身も過去へシフト（時制の一致）。  
   * 例外: **不変の真理**、**歴史的事実**は時制を変えない。  
   * 例: *The teacher said that the French Revolution **broke** out in 1789\.* (had broken ではない)  
1. **副詞 (Adverbs)**: 指示語や時・場所の表現を変更（${now \to \ then}$, ${tomorrow \to \ the \ next \ day}$ など）。

### **2\. 文の種類別パターン**

* **平叙文**: ${say \to \ say \ (that)}$, ${say \ to \ O \ to \ tell \ O \ (that)}$  
* **疑問文**:  
  * WH疑問文: ${ask \ O \ + \ \text{WH-word} \ + \ S \ + \ V}$ (肯定文の語順)  
  * Yes/No疑問文: ${ask \ O \ + \ if \ (or \ whether) \ + \ S \ + \ V}$  
* **命令文**: ${tell / ask / advise \ + \ O \ + \ (not) \ to \ V_{root}}$

## **第3章：否定表現 (Negation) \- Extra Lesson 5**

否定には「完全にそうではない（全否定）」だけでなく、「必ずしもそうではない（部分否定）」や「ほとんどない（準否定）」など、論理的なバリエーションがあります。

### **1\. 部分否定 (Partial Negation)**

「全体」を表す語を否定すると、「部分的に肯定、部分的に否定」の意味になります。  
> [!important] **公式**
> 
> * **not always**: いつも～とは限らない。  
> * **not all**: すべてが～というわけではない。  
>   * *I didn't know **all** the guests.* (全員は知らなかった＝一部しか知らなかった)  
>   * 対義語（全否定）: *I didn't know **any** (of the) guests.* (一人も知らなかった)  
> * **not both**: 両方とも～というわけではない。  
>   * 対義語（全否定）: *I didn't see **either** of the movies.* ${=}$ *I saw **neither** of the movies.*

### **2\. 準否定語 (Semi-negatives)**

not を使わずに否定的な意味を表す副詞・形容詞です。

| 種類 | 語句 | 意味 | 頻度/量 |
| :---- | :---- | :---- | :---- |
| **頻度** | **rarely** / **seldom** | めったに～ない | 頻度低 |
| **程度・量** | **hardly** / **scarcely** | ほとんど～ない | 程度低 |
| **数** | **few** | ほとんどない | 数 (可算) |
| **量** | **little** | ほとんどない | 量 (不可算) |

> [!warning] **注意点**
> 
> * ${a \ few / a \ little}$ は「少しある（肯定）」の意味。a が取れると否定になる。  
> * *He **hardly** believes such a story.* (彼はその話をほとんど信じていない。)

### **3\. 二重否定と慣用表現**

強い肯定や、論理的な強調を表します。

* **never ... without ...**: ～すれば必ず...する（...せずには～しない）。  
  * *I **never** eat this dish **without** remembering my grandmother.*  
  * (この料理を食べると必ず祖母を思い出す。)  
* **cannot ... too ...**: いくら～してもしすぎることはない。  
* **It won't be long before...**: まもなく～するだろう（～するまで長くはかからない）。

### **4\. 強い否定・その他の構文**

* **anything but**: 決して～ではない (= *far from* / *not at all*)。  
  * *The movie was **anything but** enjoyable.* (楽しむどころではなかった)  
* **nothing but**: ～にすぎない / ～でしかない (= *only*)。  
  * *It is **nothing but** a dream.* (単なる夢にすぎない)  
* **no longer**: もはや～ない (= *not ... any longer*).

## **第4章：強調・倒置 (Emphasis & Inversion) \- Extra Lesson 6**

### **1\. 否定語句による倒置**

否定の副詞が文頭に出ると、後ろは**疑問文の語順**になります。  
> [!example] **例**
> 
> * **Little** did I dream that... (～とは夢にも思わなかった)  
> * **Never** have I heard such a story. (そんな話は聞いたことがない)
