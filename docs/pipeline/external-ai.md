# 外部 AI の使い方

## 役割分担

| 役割 | 推奨ツール | 備考 |
|------|------------|------|
| 画像・手書きの文字起こし | Gemini | ページ画像を渡す |
| 空欄・未記入解答の補完 | ChatGPT または Gemini | `inferred` + 根拠必須 |
| 長時間の一気通し | Muse | 一時作業向き |
| PDF 分割・検証・マージ・アプリデータ生成 | ローカル `tools/` | 外部 AI 不要 |

## 必須ルール

1. **一時チャット優先** — 教材を長期メモリやカスタム GPT に残さない
2. **個人情報・秘密を送らない** — 氏名入り答案、採点済み答案、認証情報は送付禁止。必要なら本人確認のうえマスキング
3. **出力はリポジトリの信頼性ラベルに落とす** — AI の断定をそのまま `original` にしない
4. **ローカルでできることはローカルで** — `tools/` がカバーする工程で外部 AI を必須にしない

## プロンプトに含めるとよい指示（要約）

- 読めない文字は推測せず未確認と書く
- 数式は LaTeX
- ページ番号とファイル名を各段落に付ける
- 解答を補完した場合は根拠を一文で書く
