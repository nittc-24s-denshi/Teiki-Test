# 度数分布表，ヒストグラム，代表値



以下は，あるクラス 40 名が受験した「工学基礎数学」のテスト（100 点満点）のデータである．

**データ（40人分）**
65, 52, 45, 72, 58, 91, 68, 67, 53, 55, 61, 74, 49, 69, 66, 88, 71, 55, 84, 63,
76, 59, 94, 69, 73, 51, 80, 64, 78, 56, 89, 62, 75, 48, 81, 67, 70, 57, 86, 60

**【状況】あなたの点数は「72 点」であった．**
**【問い】** あなたはクラスの中でおよそどのような位置付けだろうか．

### [ 1 ] 代表値



データ $x_1, \dots, x_n$ 全体の傾向や特徴を 1 つの数値で代表して表したものを**代表値**という．

* **平均値 $\bar{x}$**：データの総和をデータの個数 $n$ で割ったもの：
{{手書き: 


$$\bar{x} = \frac{1}{\text{データの個数}} \sum \text{各データ}$$


}}
{{手書き: 


$$= \frac{1}{n} \sum_{i=1}^{n} x_i$$


}}


* 例：$3, 2, 5, 1, 7 \rightarrow \frac{3 + 2 + 5 + 1 + 7}{5} = 3.6$




* **メディアン（中央値）$Me$**：データを昇順 $y_1 \le y_2 \le \dots \le y_n$ に並べ直したときの真ん中の値．真ん中の数が 2 つある場合（$n$ が偶数）のときは真ん中の 2 つの平均：


* 例：$3, 2, 5, 1, 7 \rightarrow 1, 2, \underline{3}, 5, 7 \rightarrow 3$


* 例：$3, 2, 5, 1, 7, 9 \rightarrow 1, 2, \underline{3, 5}, 7, 9 \rightarrow \frac{3 + 5}{2} = 4$





**【演習 1】（個々のデータからの平均値とメディアンの算出）**

1. 5 人分の小テストデータ $(68, 74, 82, 55, 91)$ の平均値・中央値を求めよ．
**（解答）** {{手書き: 平均値 $\bar{x} = (68 + 74 + 82 + 55 + 91) \div 5 = 74$}}
{{手書き: 中央値 $Me = 74$}}


2. 冒頭の 40 人データの合計は 2701 点である．平均値 $\bar{x}$ を求めよ．
**（解答）** {{手書き: $\bar{x} = 2701 \div 40 = 67.525$}}


3. 40 人データを昇順に並べ替えたとき，20 番目は 67 点，21 番目は 67 点であった．メディアン $Me$ を求めよ．
**（解答）** {{手書き: $Me = 67$}}
