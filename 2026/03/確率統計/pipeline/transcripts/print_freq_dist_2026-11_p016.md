{{手書き: $A = \{\{1, 2\}, \{1, 3\}, \{1, 4\}, \{2, 3\}\} \qquad \overline{A} = \{\{1, 5\}, \{2, 4\}, \{2, 5\}, \{3, 4\}, \{3, 5\}, \{4, 5\}\}$}}

(2) 引いたカードの数字がどちらも 3 以上である事象を $B$ とする．$B$ と $A \cap B$ を外延的記法で表せ．
{{手書き: $B = \{\{3, 4\}, \{3, 5\}, \{4, 5\}\}, \quad A \cap B = \emptyset$}}

### [ 2 ] 確率



試行をした時，事象 $A$ の起こりやすさを 0 以上 1 以下の数で表したものを**確率**と言い，$P(A)$ と書く．

$$!!! \quad P \text{ には必ず集合を代入する} \quad !!!$$



例えば，（ちゃんとした）サイコロを振った時，

* 3 以下の目が出るという事象 $A = \{1, 2, 3\}$ の確率は $P(A) = \frac{1}{2}$ である．


* 3 の目が出るという事象 $B = \{3\}$ は根元事象であり，その確率は $P(B) = \frac{1}{6}$ である．


* 7 以上の目が出るという事象は空事象 $\emptyset$ であり，その確率は $P(\emptyset) = 0$ である．


* 1 以上の目が出るという事象は全事象 $\Omega$ であり，その確率は $P(\Omega) = 1$ である．



この例では，全ての根元事象に対して，その確率は等しく $\frac{1}{6}$ である：

$$P(\{1\}) = P(\{2\}) = P(\{3\}) = P(\{4\}) = P(\{5\}) = P(\{6\}) = \frac{1}{6}$$



事象 $A, B$ について，その確率が等しい，即ち $P(A) = P(B)$ の時，$A$ と $B$ は**同様に確からしい**という．
**ある試行の根元事象が全て同様に確からしいとき，**

$$P(A) = \frac{n(A)}{n(\Omega)}$$


が成り立つ．

**【例 2】** [例題 3.1]
2 つのサイコロを同時に投げる時，次の事象が起こる確率を求めよ．

(1) 目の和が 7 となる事象 $A$．
$n(\Omega) = (\text{2 つのサイコロを投げた時の出目の組の場合の数}) = 6 \cdot 6 = 36$.
$n(A) = n(\{(1, 6), (2, 5), (3, 4), (4, 3), (5, 2), (6, 1)\}) = 6$．よって，$P(A) = \frac{n(A)}{n(\Omega)} = \frac{1}{6}$

(2) 目の和が 8 となる事象 $B$．
$n(B) = n(\{(2, 6), (3, 5), (4, 4), (5, 3), (6, 2)\}) = 5$．よって，$P(B) = \frac{5}{36}$
