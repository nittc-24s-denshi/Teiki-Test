### [ 4 ] 回帰直線



$X$ から $Y$ のおよその値を予測するため，散布図に直線を当てはめる．このとき，$X$ を**説明変数**，$Y$ を**目的変数**という．直線を $\hat{y} = ax + b$ とすると，$x_i$ に対する**予測値**は $\hat{y}_i = ax_i + b$ である．観測値と予測値との差

$$e_i = y_i - \hat{y}_i = y_i - (ax_i + b)$$


を**残差**という．**縦方向のずれである残差の 2 乗の和**

$$Q(a, b) = \sum_{i=1}^{n} \{y_i - (ax_i + b)\}^2$$


を最小にする方法を**最小二乗法**といい，それによって定まる直線を **$Y$ の $X$ への回帰直線**という．
$v_x > 0$ のとき，傾き $a$ と切片 $b$ は一意に定まり，

$$\boxed{a = \frac{c_{xy}}{v_x}, \qquad b = \bar{y} - a\bar{x}} \qquad \left( s_y > 0 \text{ なら } a = r \frac{s_y}{s_x} \right).$$


したがって，回帰直線は必ず点 $(\bar{x}, \bar{y})$ を通る．

*証明.* $y_i - ax_i - b = (y_i - \bar{y}) - a(x_i - \bar{x}) + (\bar{y} - a\bar{x} - b)$ を 2 乗して平均すると，偏差の和 $= \sum_i (x_i - \bar{x}) = \sum_i (y_i - \bar{y}) = 0$ であることから，

$$\begin{aligned} \frac{Q(a, b)}{n} &= v_y - 2ac_{xy} + a^2 v_x + (\bar{y} - a\bar{x} - b)^2 \\ &= v_x \left( a - \frac{c_{xy}}{v_x} \right)^2 + (\bar{y} - a\bar{x} - b)^2 + v_y - \frac{c_{xy}^2}{v_x}. \end{aligned}$$


最後の項は $a, b$ に依存しないので，2 つの平方の項をともに $0$ にすればよい．$\square$

**【例 4】** データ A の回帰直線と，$x = 7$ のときの予測値・残差を求める．
$\bar{x} = 6, \bar{y} = 8, v_x = 28/3, c_{xy} = 7$ より，

$$a = \frac{7}{28/3} = \frac{3}{4}, \qquad b = 8 - \frac{3}{4} \cdot 6 = \frac{7}{2}.$$


したがって，回帰直線は

$$\boxed{\hat{y} = \frac{3}{4} x + \frac{7}{2}}.$$


$x = 7$ のとき，予測値は $\hat{y} = 35/4 = 8.75$．観測値は $y = 12$ なので，残差は $e = 12 - 8.75 = 3.25$ となる．
