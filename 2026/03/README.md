## パスを `2026/03` にした理由

既存ツリーは年度フォルダの下の年度内シリアル `YYYY/NN` だけである。年をまたぐ通し番号や、フォルダ名への期名は使っていない。`2025/01` の主な活動は2025-06前後、`2025/03` は2025-11末で、それぞれ前期中間・後期中間に対応すると推定できる。この対応は推定であり、公式に確定した回名ではない。2026年度の後期中間は、同じ年度内シリアルで `03` とする。

## 推定と確定

シラバスの週次や授業進行から見当をつけた項目は **推定** である。試験範囲としては確定していない。公式範囲表が届くまで、範囲表へ週次を写さない。`物理Ⅵ` は本人提供の課題表を公式範囲として受領済み（詳細は `物理Ⅵ/公式範囲_後期中間（課題表）.md`）。他科目は未入手。
