#### (2)鉄製水車の登場



スミートンによる [ ⑧ {{手書き: 低胸掛水車}} ] は，少なくとも40〜50%の効率で運転することができた（効率化）．このためイギリスでは，1750年頃から胸掛けタイプの水車が普及し，下掛け水車はほぼ駆逐された．さらに18世紀末以降から，イギリスでは鉄が入手しやすくなり，水車の素材には木材よりも [ ⑨ {{手書き: 鉄}} ] が利用されるようになった．初期には鉄製の車軸が利用され，やがて全部品の鉄製化となった．鉄を利用することにより，木製水車は平均5年で部品交換が必要であったが，それを大幅に延長でき（寿命100年：長寿命化），またエネルギー転換効率もさらに上昇し，直径の大型化により10馬力以上の水車が登場した（大型化）．
